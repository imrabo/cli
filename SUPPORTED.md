# imrabo Supported Platforms & Features (v0.1)

## 💻 Operating Systems
- **Windows**: 10 / 11 (x64)
- **macOS**: Sonoma / Sequoia (Apple Silicon & Intel)
- **Linux**: Ubuntu 22.04+ / Debian 12 (x64)

## 🧠 Hardware Support
- **CPU-only inference** (llama.cpp)
- **Minimum RAM**: 8GB (recommend 16GB+)
- **Disk Space**: 10GB free for model cache

## 📦 Model Support
- **Format**: GGUF (via llama.cpp)
- **Curated Models (Max 10)**:
  - Mistral 7B Instruct v0.3
  - Llama 3 8B Instruct
  - Phi-3 Mini (4k/128k)
  - Qwen2 7B
  - (Others TBD)

## ⚙️ Backend
- **Core**: `llama.cpp`
- **Interface**: imrabo Go Runtime API
- **CLI**: Node.js / TypeScript
